# HW 8 Разделение монолита на сервисы

### Общая информация
Модуль диалогов вынесен в отдельный сервис(в прошлой ДЗ).

Добавил версионирование API в URL.

Добавил middleware, которая прописывает заголовок X-Request-ID.

X-Request-ID передается между сервисами, логируется.
Это позволяет облегчить процесс отладки запроса.


Сервис social-network вызывет сервис message-service по REST API с помощью ассинхроной библиотеки httpx
